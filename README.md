# 연봉 오퍼 설계기 (Offer Designer)

외국계 반도체 장비사 Repair Engineer 채용 시 후보자 정보(경력·학력·현재 보상 등)를 입력하면
시장 데이터 + 현 연봉 + 내부 Job Grade 밴드 + 내부 비교군을 종합해 **하한 / 권장 / 상한 오퍼**를 제안하는 웹앱입니다.

## 접속 · 회원
- 웹 주소로 접속 → **회원가입(닉네임 + 비밀번호)** → 관리자가 **회원 관리** 탭에서 승인 → 로그인
- 수집 정보: 닉네임, 비밀번호(bcrypt 일방향 암호화), 가입·접속 일시. 이메일·실명은 받지 않습니다.
- 후보자·내부 직원 연봉 등 **입력 데이터는 서버로 전송되지 않고** 각 기기 브라우저에만 저장됩니다.
- iPad: Safari로 접속 → 공유 → **홈 화면에 추가** 하면 앱처럼 사용할 수 있습니다.

## 처음 한 번: 회사 설정 파일 가져오기
웹사이트에는 회사 내부 정보가 들어 있지 않습니다(예시값만 있음).
HR 담당자가 전달한 `company-settings.json`을 **설정 → 회사 설정 파일 → 설정 가져오기**로 불러오면
실제 Grade 밴드·포지션명·수당(명절수당, 4대보험 지원)·복지포인트 정책이 그 기기에 저장됩니다.

## 탭 구성
1. **오퍼 설계** – 후보자 입력, 3개 시나리오(PIR·CR·인상률·이탈 리스크), 포지셔닝 차트, 내부 형평성 비교, 체크 포인트, 사측 보고용 근거 문구
2. **오퍼 시트** – 'COMPENSATION SPREADSHEET - OFFER' 양식 자동 작성 (항목별 수당·Festival·Other(4대보험)·Flexible Benefit 포함, CSV/PDF)
3. **후보자용 보상 요약** – Total Rewards 비교표 (PDF)
4. **시장 데이터** – 한국/글로벌 조사 요약, 경력별 시장 기준표, 데이터 업데이트 이력
5. **저장 목록** – 후보자 저장·불러오기·JSON/CSV 내보내기
6. **설정** – Grade·포지션 밴드, 수당·복리후생 정책, 4대보험 요율, 추천 규칙, 내 계정
7. **회원 관리** (관리자만) – 가입 승인/거절/삭제, 관리자 지정

## 계산 규칙 요약
- 유효 경력 = 관련 경력 + 비관련 경력 × 50%
- 시장 목표 = 경력별 시장 계약연봉 P50 × (학력·자격증·면접·영어·교대 보정)
- 현 연봉 기준 = 현재 실질 총현금(최근 1년 성과급의 70% 인정) × (1 + 시장 대비 위치별 목표 인상률)
- 권장안 = 현 연봉 기준 60% + 시장 기준 40% → 하한(최소 +5%) ~ Grade Max 범위 내 조정
- **4대보험 근로자분 지원(Other Allowances)** = 연 기본급 × (국민연금 4.75% + 건강 3.595% + 장기요양 0.4724% + 고용 0.9%) ≈ 9.72%, 국민연금은 기준소득월액 상한 적용. 고정수당에 포함되므로 기본급 산정 시 함께 고려됨
- **내부 비교군**: 직원별 현재 연봉 × (1 + 예상 인상률) 과 오퍼를 비교, 최고치 초과 시 '연봉 역전' 경고
- 나이는 기록만 하고 산식에 반영하지 않음 (고령자고용법상 임금 연령차별 금지)

## 데이터 자동 업데이트
`data/market.js`는 매월 1일 예약 작업이 환율·최저임금·4대보험 요율·시장 조사 데이터를 재조사해 갱신합니다.
변동이 15% 이상인 값은 자동 반영하지 않고 이력에 '검토 필요'로 남깁니다. 업데이트 이력은 시장 데이터 탭 하단에서 확인할 수 있습니다.

## 파일 구성
- `index.html`, `js/`, `data/market.js`, `config.js` – 웹앱
- `supabase/schema.sql` – 회원 승인 DB 스키마 (닉네임·비밀번호 해시만 저장)
- `reports/` – 한국·글로벌 시장 조사 원문(출처 URL·신뢰도 포함)
